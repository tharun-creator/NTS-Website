# NTS Website Color Palette

## Core Brand Colors

| Name | Hex | Usage |
|---|---:|---|
| Cream | `#F4ECDF` | Main light background, cream text/fills |
| Maroon | `#4A151C` | Primary brand text and UI color |
| Deep Background | `#150A09` | Dark site background |
| Maroon Background | `#2C0F14` | Dark maroon sections |
| Coral Orange | `#E9542E` | Primary accent, CTAs, hover states |
| Gold | `#C9A15A` | Decorative accent |
| Soft Gold | `#E3C98F` | Secondary decorative accent |
| Muted | `#A8968A` | Muted text/accent tone |
